# Retro Laser Dodge

A lightweight arcade-style 2D retro web game built with pure HTML5 Canvas and vanilla JavaScript.

## Play
- Live on GitHub Pages: https://rahulatwork77-ui.github.io/retro-laser-dodge/

## Features
- Pure web stack: 0 dependencies
- Responsive keyboard controls (Arrow Keys / WASD)
- Scaling difficulty & local high-score persistence
